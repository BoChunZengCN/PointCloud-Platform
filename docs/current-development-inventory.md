# 点云平台当前开发功能盘点

**盘点日期：** 2026-09-02

**盘点分支：** `codex/phase15d-human-decisions-bindings`

**状态基线：** Phase 15D 人工决策、不可变绑定与双工作台（已完成本地开发与验收）
**说明：** 状态依据当前代码、阶段文档、Phase 15A SDD 进度和 Git 历史综合判断。外部工具边界已实现不等于外部生产工具本身已经随平台交付。

## 1. 总体状态

平台已经形成三条基础能力链：

1. **点云数据链：** LAS/LAZ/FLS 接入、质检、切片、分析、分割、质量与交付门禁。
2. **可视化链：** Potree 发布、Gaussian Splatting 编排、统一查看器清单和前端工作台。
3. **语义与模型链：** 分割纠正、反馈数据、版本化模型库、确定性采样、生产/Challenger 特征索引和可解释模型候选检索。

**Phase 15A、Phase 15B-1、Phase 15B-2、Phase 15C 和 Phase 15D 已完成。** 系统可以从已审查分割对象检索候选、执行刚性配准，再由人工确认生成不可变绑定。下一开发目标是 Phase 15E 实物参考点云模板；持续优化仍属于后续独立里程碑。Phase 15D 操作与边界见 [中文说明](phase15d-human-decisions-bindings.md)。

Phase 15A 最终质量门禁的全量验证结果为：`734 passed, 4 skipped, 1 warning`。跳过项主要是当前 Windows 环境无法创建符号链接的适用性测试；警告为既有 Starlette/httpx 弃用提示。

## 6. 当前明确限制

- 真实 FLS 转换器、PDAL、PotreeConverter、Open3D 和 3DGS 训练器主要通过外部工具适配，不全部内置。
- Phase 13A 运行质量是无黄金标注的代理指标，真实准确率以 Phase 13B 黄金评估为准。
- 参数搜索和反馈数据目前不会自动修改生产配置或触发在线训练。
- Phase 15C 已能对 Phase 15B-2 Top-K 候选执行刚性配准并输出三态报告，但仍不自动形成对象—模型绑定。
- 检索分数是候选排序依据，不等同于配准残差、安装可行性或最终业务确认。
- 模型匹配业务界面和专业管理界面已实现；统一三维对象查看器仍未实现。
