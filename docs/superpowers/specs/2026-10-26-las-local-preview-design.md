# 平台内 LAS 点云直接预览设计

## 意图与范围

在现有 `frontend/viewer.html` 展示入口增加“直接预览 LAS”，供用户检查本轮导出的 4 个原始点候选。用户在浏览器中选择本机 LAS 文件，页面展示可旋转、缩放和切换视角的真实 RGB 点云，并显示点数、尺寸和加载状态。它是质量检查入口，不改变分割结果或发布状态。

本轮只处理未压缩 LAS 1.2/1.3、点格式 2/3（XYZ+RGB），覆盖本次真实样本 LAS 1.2/格式 2。不提供 LAZ、Mesh、服务器上传、文件持久化或对候选的管线/设备自动命名。完整 1.15 GB 场景不在浏览器直接加载范围内，后续通过 Potree/COPC 分层发布。

## 已有基础与方案取舍

现有资产展示页可嵌入 HTML，纠正和重建页有有界点集的 Canvas 预览，但不能直接解析用户选中的 LAS。Potree 发布接口依赖外部 `PotreeConverter`，当前机器未检测到该命令。

- 方案 A（采用）：在现有展示页增加本地 LAS 预览入口，以浏览器原生 File API + WebGL 解析和绘制。优点是不安装外部工具、不上传私有扫描、4 个候选可立即验收；限制是仅适合有界大小的 LAS，浏览器 WebGL 可用性仍须现场验证。
- 方案 B：先安装 PotreeConverter 并发布转换结果。适合全量大场景，但增加部署依赖和转换产物管理，不能解决当前机器的即时验证。
- 方案 C：将 LAS 上传到新 API 再转码。能统一资产管理，但引入 1 GB 级上传、安全、配额与持久化语义，超出本轮范围。

## 行为与边界

1. 页面通过本地文件选择器选择一个或多个 `.las`；文件内容不经 API、网络请求或 localStorage。文件切换仅替换内存中的显示缓存。
2. 严格校验 LAS 签名、版本、点格式、记录长度、比例尺、坐标偏移、点数与文件长度。仅接受小于等于 128 MiB、点数小于等于 750,000 的文件；超限明确提示使用分层发布，不静默采样。
3. 支持格式 2/3 的 RGB 16 位颜色到显示颜色转换，XYZ 以双精度解码后减去场景中心再转 32 位 GPU 坐标。每个获准文件加载全部点；页面明确标注“全部原始点”，不把显示点数误当作扫描精度。
4. WebGL 不可用时显示清楚的错误，不把静态占位图当作成功预览；切换文件时销毁旧 GPU 缓冲，读取失败不得留下旧图并误标为新文件。
5. 展示顶视、正视、侧视和自由旋转、滚轮缩放；文件名用安全文本节点呈现。页面与现有展示页互相链接。

## 验收

- 单元测试覆盖有效 LAS 2/3、RGB/坐标解码、头部损坏、截断、过大、LAZ 拒绝和有限点数上限。
- 对 4 个真实候选 LAS 分别验证解码点数与已核验清单一致，至少一个候选抽样对比原始点坐标/颜色；不修改源文件。
- 在浏览器中实际打开候选 LAS，验证旋转、缩放、视角切换和状态提示。基础测试全绿、Git 不包含真实扫描文件。
